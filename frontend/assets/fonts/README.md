# Local fonts

Variable fonts downloaded from the Google Fonts repository on 2026-09-23:

- Lora (upright and italic): https://github.com/google/fonts/tree/main/ofl/lora — hero, section headings and specialist names.
- Manrope: https://github.com/google/fonts/tree/main/ofl/manrope — form subheadings, buttons and prices.
- Golos Text: https://github.com/google/fonts/tree/main/ofl/golostext — body text, explanations and form fields.

All are distributed under the SIL Open Font License 1.1. Original licenses
are included as Lora-OFL.txt, Manrope-OFL.txt and GolosText-OFL.txt. Font binaries are unmodified.
All font requests are local; no runtime connection to Google Fonts is required.
