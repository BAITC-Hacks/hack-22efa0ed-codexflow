# CodexFlow — умный подбор подрядчиков

Актуальная общая инструкция по всему репозиторию: [главный README](../README.md). Этот документ сохраняет продуктовый обзор команды.

Сервис помогает организатору события выбрать подрядчиков из каталога по городу, дате, формату, категории и бюджету. Вместо длинного списка он показывает до трёх подходящих профилей и объясняет, чем каждый соответствует запросу.

## Возможности

- Подбор подрядчиков и площадок из каталога по городу и категории.
- Проверка даты занятости, бюджета и формата; язык и длительность можно указать дополнительно.
- До трёх карточек с индивидуальными объяснениями.
- Понятные отдельные исходы: подобрали варианты, категории нет в городе, либо кандидаты есть, но условиям никто не соответствует.
- Стабильный порядок при одинаковом запросе: цена «от» по возрастанию, затем ID профиля.
- Отображение всех категорий подрядчика и меток происхождения данных.
- Локальный интерфейс и HTTP API.

Сервис не бронирует подрядчиков и не отправляет им заявки или уведомления.

## Запуск

Нужны Python 3.10 или новее. Все команды установки и запуска выполняются из recommendation-logic.

### Windows PowerShell

```powershell
cd recommendation-logic
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

### macOS / Linux

```bash
cd recommendation-logic
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

Откройте интерфейс: http://127.0.0.1:8000/ui/  
Интерактивная документация API: http://127.0.0.1:8000/docs  
Проверка состояния сервера: http://127.0.0.1:8000/health

Чтобы остановить сервер, нажмите Ctrl+C в терминале.

Из папки recommendation-logic:

```bash
python -m unittest discover -s tests -v
```

## Пример запроса

```bash
curl -X POST http://127.0.0.1:8000/recommendations \
  -H "Content-Type: application/json" \
  -d '{
    "city": "Алматы",
    "event_date": "2026-10-07",
    "event_format": "свадьба",
    "category": "Ведущий",
    "budget_kzt": 1000000,
    "language": "казахский"
  }'
```

Язык и длительность можно не передавать. Для длительности используйте поле duration_hours, например 4.5.

Успешный HTTP-ответ содержит:

- outcome — matches, category_absent или no_match;
- cards — от нуля до трёх карточек;
- message — объяснение результата;
- stats — число профилей выбранных города и категории, число подходящих и причины исключения.

В карточке есть имя, все категории профиля, город, цена «от», объяснение и флаги synthetic, city_imputed, price_imputed.

## Как устроен подбор

1. Сервис проверяет и нормализует параметры заказа.
2. Находит профили выбранного города, где запрошенная категория входит в список категорий. Профиль с несколькими категориями не дублируется.
3. Исключает занятых на дату, превышающих бюджет, неподходящих по формату, а также по указанному языку или длительности.
4. Сортирует оставшихся по цене «от» и ID и берёт первые три карточки.
5. Формирует объяснение по структурированным данным и конкретному факту из описания профиля.

Порядок отражает цену и постоянный ID, а не рейтинг качества. Если у профиля max_hours отсутствует, длительность сама по себе его не исключает: услуга не привязана к присутствию на площадке, а срок выполнения нужно согласовать. Причины отказа могут пересекаться, поэтому их счётчики не всегда складываются в число профилей.

Опциональный выбор фразы моделью выключен по умолчанию. Он не меняет кандидатов, цены или порядок карточек. Запуск без ИИ не требует API-ключа. Подробности включения и ограничений — в [AI.md](../recommendation-logic/AI.md).

## Каталог и метки данных

Каталог содержит 66 анонимизированных профилей и календарь занятости с 23 сентября по 31 декабря 2026 года. В нём есть площадки, подрядчики и синтетические записи.

- synthetic означает, что профиль синтетический;
- city_imputed означает, что город проставлен при подготовке датасета;
- price_imputed означает, что цена проставлена при подготовке датасета.

Эти метки независимы и должны отображаться отдельно. Цена в каталоге — стартовая цена «от», не итоговая смета. За пределами окна календаря доступность неизвестна.

## Ограничения

- Рекомендация не подтверждает фактическое бронирование; доступность отражает календарь предоставленного датасета.
- Цены ориентировочные и могут быть проставлены при подготовке данных.
- Каталог анонимизирован и включает синтетические профили; метки показывают их происхождение.
- Подбор детерминированный, без нейросетевого рейтинга. Объяснения должны опираться на поля каталога и факты описания.
