## Объём проверки

- 105 Python-тестов основного набора, 12 JavaScript-тестов, 6 отдельных тестов помощника: все прошли, всего 123.
- В основной набор входит новый `tests/test_spec_acceptance.py`: 112 существующих сочетаний города, категории и формата на всех 100 днях календаря. Всего 11 200 запросов; в результатах встретились все 66 профилей. Язык и длительность в этом проходе не ограничены, бюджет технически высокий. Это не перебор всех числовых значений.
- Дополнительно 10 000 запросов с разными бюджетами, языками и длительностью сравнены с независимым эталоном: расхождений нет.
- 2 000 настоящих HTTP-запросов к отдельному однопроцессному локальному серверу: все HTTP 200, без ошибок или расхождений с ожидаемым результатом.
- 12 некорректных входов: ожидаемые 400/413/422, ни одного 500.
- Каталог масштабировался до 6 600 копий только в памяти теста: исходные данные не изменялись.
- Живой API на 8013: шесть контрольных кейсов и повтор запроса прошли; ответы порядка 2–16 мс.
- Браузер: ведущие, смена даты, флористы, низкий бюджет, отсутствие категории, исправленные лайв-бэнды; ввод описания → уточнение языка → подтверждение → основная форма. Ошибок JS в этой проверке нет.
- `pip check`: конфликтов установленных зависимостей нет. Это не сканирование известных уязвимостей.

## Исправления по результатам проверки

1. Два лайв-бэнда HK-23752 и HK-83709 раньше получали одинаковую цитату о репертуаре. Теперь конкретные сведения о музыкальном составе имеют больший вес; у второго профиля объяснение указывает четыре вокалиста, струнный квартет и инструменты из его описания. Цены и порядок не менялись.
2. Представление «Мы — название группы» и несколько рекламных лозунгов больше не используются как отличительный факт. Если сведений мало, ответ честно сообщает это и использует структурированные условия.
3. Опциональная модель не может заменить разные объяснения одинаковыми: при таком результате возвращаются исходные объяснения по правилам.
4. Помощник понимает «2 часа 30 минут» как 2,5 часа, а также отдельные минуты. Отрицательные значения и превышение 168 часов отклоняются.
5. «Язык любой» сбрасывает прошлое языковое ограничение. «До 4 часов» не превращается в бюджет 4 тенге.
6. Добавлены тесты на каждый исправленный сценарий и полный проход календаря.

## Материал для автора README и выступления

Пайплайн: загрузка 66 профилей → валидация и нормализация запроса → город и категория → дата, бюджет, формат, язык, длительность → сортировка по стартовой цене и ID → максимум три карточки → фактические объяснения и причина ограниченной/пустой выдачи.

Первое предложение карточки — подтверждённая особенность профиля. Второе связывает доступную дату, формат, бюджет и дополнительные пожелания с запросом. Никакие цены, навыки или доступность не придумываются. `max_hours=null` означает услугу без привязки к присутствию, а не обещание бесконечной работы.

Основной подбор детерминированный, без обязательной нейросети и без ключей. «Опишу своё событие» — русскоязычный разбор по правилам с уточнениями и явным подтверждением. Это не универсальный ИИ-чат. Кнопка «Справочник» — локальная инструкция по сайту, без API-вызовов.

Настоящий LLM опционален и отключён по умолчанию. Он может выбирать факт из исходного текста, но не менять состав выдачи или цены. В этой проверке транспорт модели был замокан, платных вызовов не было. Не утверждать в презентации, что по умолчанию работает генеративная модель или семантический рейтинг.

Начало работы и контракт: [инструкция интеграции](../recommendation-logic/HANDOFF.md). Параметры показа: [демо-кейсы](demo-cases.md), [JSON-запросы](../recommendation-logic/examples/demo-cases.json). Безопасность: [границы защиты](../recommendation-logic/SECURITY.md).

## Как повторить

Из `recommendation-logic/`:

```powershell
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
node --test qa/frontend-integration.test.mjs
python qa/stress_check.py --output qa-results.json
python -m uvicorn src.api:app --host 127.0.0.1 --port 8000
```

В другом терминале из той же папки:

```powershell
python qa/demo_check.py --base-url http://127.0.0.1:8000
```

Сайт: `http://127.0.0.1:8000/ui/`. Для живого демо не добавлять `?demo=1`: этот режим намеренно показывает сохранённые примеры.

Шесть дополнительных тестов помощника из корня репозитория, в PowerShell:

```powershell
python -c "import sys,unittest; sys.path.insert(0,'recommendation-logic'); r=unittest.TextTestRunner().run(unittest.defaultTestLoader.loadTestsFromName('contractor_assistant.test_chat')); sys.exit(not r.wasSuccessful())"
```

## Ограничения и непроверенное

Сервер проверен локально на Windows, Python 3.13.12; внешний хостинг, TLS, свежая установка на другой машине и настоящее подключение модели не проверялись. Зависимости пока заданы диапазонами версий. Предупреждение Starlette о тестовом адаптере httpx не мешает прохождению проверок.

Разбор сложной естественной речи, неоднозначных отрицаний и нескольких альтернативных заказов не гарантируется; пользователь должен проверить распознанные условия или заполнить форму. Бронирование, заявки, платежи и уведомления не реализованы и не требуются ТЗ. Календарь ограничен 23.09–31.12.2026. Каталог содержит анонимизированные/синтетические данные, не реальные гарантии доступности специалистов.

Проверка отсутствия точных дубликатов не заменяет редакторскую оценку интересности каждого текста. Для новых или полностью одинаковых профилей без отличительных фактов сервис честно сообщит недостаточность данных, а не станет выдумывать отличия.
